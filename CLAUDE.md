# Codex-Code-Remote

Node.js app to control Codex CLI remotely via multiple messaging platforms (Email, Telegram, LINE, Desktop).

## Tech Stack

- Node.js / npm

## Key Files

- `claude-remote.js` - Main application
- `claude-hook-notify.js` - Hook notifications
- `smart-monitor.js` - Smart monitoring

## Key Directories

- `config/` - Configuration files
- `assets/` - Static assets

## Features

- Multi-channel notifications
- tmux integration
- Execution tracing
- i18n support

## Configuration

- Config via `.env` file
- Run `setup-telegram.sh` for Telegram bot setup
